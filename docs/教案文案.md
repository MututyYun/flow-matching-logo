# 少走弯路————使用flow matching降低扩散模型的迭代次数

讲reflow以前，先粗略讲什么是difussion，也就是扩散模型。difussion，如今已经很常用，譬如AI绘画，AI修图等等。
其原理简单来说，就是从一个简单的分布出发，比如高斯分布，逐步推演出一个复杂的分布，比如渲染后对人类有意义的张量的分布。这个过程就叫flow。
而从高斯分布推演出我们可以看的图像，在空间中有无数种走法，flow matching就是不管选哪一种走法都能用这个框架来训练。传统的difussion模型如stable difussion选取的就是其中一种特定的走法，也就是comfyUI里的采样器。不过在传统方法里，这条路径一般是曲线，数学上一般会有一个flow的微分形式，但在这里不是我们要讨论的重点，只是说明，需要用欧拉差分之类的数值迭代方法求解一个微分方程。迭代次数越多，误差越小，相应的时间也要更久，为了达到我们生图的质量要求，常常需要迭代非常多步，这就是早期扩散模型生图慢的原因。
而2022年的论文flow matching for generating modeling，则提出了一种不一样的方法：用直线构造路径。…………我们的这个展示是为了演示这种方法确实降低了迭代次数……一共多少层，每层多少个神经元，总参数量不超过1M，训练就是在目标图形中随即撒……个点 每一轮随机与底噪连若干条直线，让神经网络去学直线的方向…………（解释我们的实验）
